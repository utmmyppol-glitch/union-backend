## 배포 순서

### 1. 소스 가져오기

```bash
mkdir -p /opt/union && cd /opt/union

git clone https://git.unionsystems.co.kr/unionsystems/union-backend.git
git clone https://git.unionsystems.co.kr/unionsystems/union-frontend.git
git clone https://git.unionsystems.co.kr/unionsystems/dataware-frontend.git
git clone https://git.unionsystems.co.kr/unionsystems/backoffice-frontend.git
```

### 2. Backend 환경변수

```bash
cd /opt/union/union-backend
cp .env.example .env
vi .env
```

| 변수 | 운영 시 |
|---|---|
| `SPRING_PROFILES_ACTIVE` | `prod` |
| `DB_PASSWORD` | 운영 비밀번호 |
| `JWT_SECRET` | 운영용 시크릿 키 |
| `MAIL_USERNAME` / `MAIL_PASSWORD` | Gmail 계정 / 앱 비밀번호 |
| `CORS_ALLOWED_ORIGINS` | 운영 도메인 |

### 3. Backend + DB 실행

```bash
docker compose up -d --build
```

- PostgreSQL 17 + DB 초기화 (sql/ 자동 실행)
- Spring Boot 빌드 + 실행 (8080)

```bash
curl http://localhost:8080/actuator/health   # {"status":"UP"} 확인
```

### 4. Frontend 빌드 및 실행

```bash
# union-frontend (포트 3000)
cd /opt/union/union-frontend
echo 'NEXT_PUBLIC_API_URL=https://union.도메인/api/union' > .env.local
npm install && npm run build
pm2 start npm --name union-frontend -- start -- -p 3000

# dataware-frontend (포트 3001)
cd /opt/union/dataware-frontend
cat > .env.local << 'EOF'
NEXT_PUBLIC_API_URL=https://dataware.도메인/api/dataware
NEXT_PUBLIC_BACKOFFICE_URL=https://admin.도메인
EOF
npm install && npm run build
pm2 start npm --name dataware-frontend -- start -- -p 3001

# backoffice-frontend (포트 3002)
cd /opt/union/backoffice-frontend
echo 'NEXT_PUBLIC_API_URL=https://admin.도메인/api' > .env.local
npm install && npm run build
pm2 start npm --name backoffice-frontend -- start -- -p 3002

pm2 save && pm2 startup
```

### 5. Nginx

```nginx
# /etc/nginx/conf.d/union.conf

server {
    listen 80;
    server_name union.도메인;
    location / { proxy_pass http://localhost:3000; proxy_set_header Host $host; }
    location /api/ { proxy_pass http://localhost:8080; proxy_set_header Host $host; }
}

server {
    listen 80;
    server_name dataware.도메인;
    location / { proxy_pass http://localhost:3001; proxy_set_header Host $host; }
    location /api/ { proxy_pass http://localhost:8080; proxy_set_header Host $host; }
}

server {
    listen 80;
    server_name admin.도메인;
    location / { proxy_pass http://localhost:3002; proxy_set_header Host $host; }
    location /api/ { proxy_pass http://localhost:8080; proxy_set_header Host $host; }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d union.도메인 -d dataware.도메인 -d admin.도메인
```

## 업데이트 배포

```bash

git pull && npm install && npm run build && pm2 restart dataware-frontend
```
